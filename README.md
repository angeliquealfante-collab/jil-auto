# Jil Auto

Create a clean, single-page landing hero for an app called "JIL". 

Theme: Dark mode (#09090B) with dark glassmorphism cards and vibrant purple accents (#7C3AED).

Layout:

1. Top Bar: App name "JIL" on the left, and an "API Key" settings button on the right that opens a popup modal to save a Gemini API Key to localStorage.

2. Hero Section: 

   - Headline: "Automate Your Agency's Local SEO Operations"

   - Subheadline: "Turn repetitive, manual tasks into single-click AI workflows."

   - Main CTA Button: A glowing purple button that says "Launch Workspace ->".

3. Feature Cards: 4 preview cards showing upcoming tools (Yoast Meta Generator, Review Responder, Catalog Builder, 12-Week GBP Calendar).
